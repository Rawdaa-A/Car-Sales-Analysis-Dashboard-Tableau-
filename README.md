# 🚗 Car Sales Analysis Dashboard (Tableau)

## 📌 Project Overview
This project analyzes automobile sales data using Tableau to generate actionable insights.  
The dashboard transforms raw relational data into clear visual stories focusing on revenue, customer behavior, and product performance.

---

## 📊 Dashboard Preview
![Dashboard](screenshots/dashboard.png)

---

## 📁 Datasets Used
- transactions_table.csv – Sales transactions data  
- customers_table.csv – Customer demographics  
- vehicles_table.csv – Vehicle details (Make, Model, Price, Color)  
- dealerships_table.csv – Dealership locations  

---

## 📊 Key Insights
- 💰 Total Revenue: **$394M**
- 👥 Customers: **200**
- 🚗 Total Transactions: **7,443**
- 💵 Avg Car Price: **$53K**

### 📈 Insights:
- Peak sales occurred between **2023–2025**
- **Washington & Michigan** are top-performing regions
- Most popular models:
  - Buick Enclave  
  - Mazda CX-5  
- Most preferred car colors identified
